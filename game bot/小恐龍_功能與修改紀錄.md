3. 修改下降時間

我：下降時間幫我修改

助理：說明：Chrome 小恐龍的實際下降時間由遊戲物理引擎控制，不能單純透過 time.sleep() 修改。

我：設定0.01

助理：將原本的：time.sleep(.015)

修改為：

不代表實際下降時間縮短至 0.01 秒。

STATE = '''(() => {
 const r=globalThis.__pythonDino, t=r.tRex;
 return {
   obstacles:r.horizon.obstacles.map(o=>({
     x:o.xPos,
     width:o.width,
     y:o.yPos,
     type:o.typeConfig.type
   }))
 };
})()'''

功能

o.typeConfig.type  障礙物種類

t.xPos  恐龍 X 座標

t.yPos  恐龍 Y 座標
