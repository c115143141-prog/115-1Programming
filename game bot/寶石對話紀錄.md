## 2. 寶石座標函式

**我：**
> 在 game bot 中新增一個 code cell，basex / basey 是左上角寶石中心點，畫面共 8x3 顆寶石，間距在 gap 中。寫一個函式，接受 row（r）、column（c），回傳該寶石的位置。

**助理：**（先確認放置位置，選擇「加到 `game bot/寶石炸彈.py`」後實作）

```python
basex = int(LEFT + CW / 2)
basey = int(TOP + CH / 2)
gap = (CW, CH)

def gem_pos(r, c):
    """回傳第 r 列（row）、第 c 行（column）那顆寶石的中心點 (x, y)。"""
    gap_x, gap_y = gap if isinstance(gap, (tuple, list)) else (gap, gap)
    return int(basex + c * gap_x), int(basey + r * gap_y)
```

說明：`x = basex + c * gap_x`、`y = basey + r * gap_y`；`gap` 可為單一數字或 `(水平, 垂直)`。
